# Lessbit Support

Lessbit is built around one idea: no ads, no payments, no accounts. Use less, bit by bit.

## Quick help

- Allow Screen Time access when Lessbit first opens.
- Choose the apps or categories you want to use less.
- Set a shared daily limit, start a focus session, or add a schedule.
- If restrictions stop working, open iOS Settings and reconnect Screen Time access from Lessbit.

All settings and detox history remain on your device. Lessbit does not offer purchases or subscriptions.

For support, [open an issue on GitHub](https://github.com/ghkdqhrbals/portfolios/issues/new?title=Lessbit%20Support).

# Lessbit 지원

Lessbit의 원칙은 단순합니다. 광고 없음, 결제 없음, 계정 없음. 조금씩 덜 사용하세요.

## 빠른 도움말

- 처음 실행할 때 Screen Time 접근을 허용하세요.
- 덜 사용하고 싶은 앱 또는 카테고리를 선택하세요.
- 공유 하루 제한, 집중 또는 예약을 설정하세요.
- 제한이 작동하지 않으면 iOS 설정에서 Screen Time 권한을 확인한 뒤 Lessbit에서 다시 연결하세요.

모든 설정과 디톡스 기록은 기기에만 남습니다. Lessbit에는 구매나 구독이 없습니다.

지원이 필요하면 [GitHub에 문의를 남겨 주세요](https://github.com/ghkdqhrbals/portfolios/issues/new?title=Lessbit%20Support).
