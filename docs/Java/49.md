  # Guestbook Home Server Setup Process

  1. Buy a domain, use Cloudflare as the nameserver, and configure a tunnel to the home server.
  2. Build a FastAPI + SQLite guestbook server.
  3. Automate deployment to the home server through a GitHub Actions self-hosted runner.
  4. Configure it so it can also be tested locally.
  5. Configure a Cloudflare SSH tunnel for remote work.
  6. Apply the guestbook/comment feature to the blog.
  7. Publish a GitHub Action to [GitHub Actions Marketplace](https://github.com/marketplace/actions/ga-stats-fetcher) that receives GA information and generates a JSON file.
  8. Configure automation so GitHub Actions periodically fetches GA statistics.

# 방명록 홈서버 구축 과정

1. 도메인 구매 및 네임서버를 cloudflare 로 두고 홈서버에 tunnel 설정
2. FastAPI + SQLite 방명록 서버
3. github action self hosted runner 홈서버로 배포 자동화
4. 로컬에서도 테스트 가능하도록 설정
5. 원격작업 위해 cloudflare ssh 터널 설정
6. 블로그에 방명록/댓글 적용
7. [git actions 마켓플레이스](https://github.com/marketplace/actions/ga-stats-fetcher)에 GA 정보를 입력받아 JSON 파일을 생성해주는 GitHub Action 배포
8. git actions 에서 GA 통계정보를 주기적으로 받아오는 자동화 설정
